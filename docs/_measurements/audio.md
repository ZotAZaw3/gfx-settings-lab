# Audio settings: measured cost

Generated by `tools/audio_bench` (offline render of the demo soundscape, 8 s per row). CPU is the audio thread's busy time as a **percentage of one core** (time spent mixing / duration of audio produced). RAM is the memory the mixer, streams and device buffer allocate for that setting; decoded sound assets add a constant 1687 KB. GPU cost of every audio setting is 0: audio never touches the GPU.

Machine: cloud container, 4 vCPU, Release build (-O3). Absolute numbers are slower than a desktop CPU; compare rows with each other.

Baseline: High preset (96 voices, cubic resampler, high reverb, multi-ray occlusion), stereo, 48 kHz, 32-bit float, 480-frame buffer, 69 playing voices (5 scene sounds + 64 crowd emitters).
